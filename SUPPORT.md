# Getting help

| You want to… | Go to |
|---|---|
| Ask a question or share an idea | [Discussions](https://github.com/faraj118/personal-network-analyzer/discussions) |
| Report a bug | [New issue → Bug report](https://github.com/faraj118/personal-network-analyzer/issues/new/choose) |
| Request a feature | [New issue → Feature request](https://github.com/faraj118/personal-network-analyzer/issues/new/choose) |
| Report a security problem | Privately, see [`SECURITY.md`](SECURITY.md) |
| Contribute | [`CONTRIBUTING.md`](CONTRIBUTING.md) |

Before asking, check the [README](README.md), the [`docs/`](docs/) folder and existing
issues.

PNCA is maintained by volunteers in their spare time, so there's no guaranteed response
time. Clear questions with steps to reproduce get answered fastest. Never paste real personal
data (contacts, exports, card photos) into an issue or discussion.
